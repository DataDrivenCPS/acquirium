Build a turbidity alarm pipeline#

This pipeline cleans turbidity readings and raises an alarm when they stay above a limit. Turbidity measures how cloudy water is, in nephelometric turbidity units (NTU).

Analyser readings → Clean turbidity → Sustained alarm

For a single calculation with a few sample readings, start with Build your first soft sensor.

From the repository root, run the example on a temporary server.

uv run --locked python -m examples.turbidity.run

The script loads a small plant model with three filters and a combined outlet. Each location sends two readings per minute for 25 minutes. Filter 3 has a high period, a fault code, a missing minute, and a spike. Plot of the sample readings

Deploy the cleaner#

After registering the plant, the script selects turbidity measurements and groups them by location. Each location has a maximum distance from the local median for rejecting spikes. The rolling window steps once per minute. ReplacementOutput() makes the cleaned values the default for each analyser.

calculations = Path(__file__).with_name("calculations.py")
# Find the turbidity measurements and their plant locations.
turbidity = (
    client.query()
    .measurement(alias="turbidity", quantity_kind=TURBIDITY)
    .context(alias="location")
)
clean_app = aq.App(
    name="turbidity-clean",
    inputs={
        "raw": aq.Selection.from_query(
            turbidity,
            measurement="turbidity",
            group="location",
            # Set the largest acceptable deviation from the local median.
            parameters={
                "urn:turbidity:filter-1": {"threshold": 1.0},
                "urn:turbidity:filter-2": {"threshold": 1.0},
                "urn:turbidity:filter-3": {"threshold": 1.0},
                "urn:turbidity:combined": {"threshold": 0.5},
            },
        ),
    },
    # Make cleaned values the default for the analyser measurement.
    outputs={"turbidity": aq.ReplacementOutput()},
    function=aq.PythonFunction.from_file(calculations, "clean"),
    # Clean each minute using readings on either side.
    window=aq.Rolling(
        lookback=pd.Timedelta("5m"),
        step=pd.Timedelta("1m"),
        lookahead=pd.Timedelta("5m"),
    ),
)
client.deploy_app(clean_app)

Cleaning steps#

For each output minute, the cleaner sees five minutes of analyser readings on either side. The pd.DataFrame annotation asks Acquirium for a pandas frame. The value column holds numbers, and text fault codes have no numeric value. The function drops faults and spikes, averages by minute, and interpolates gaps between valid minutes. The app publishes the result for its output minute.

def clean(frame: pd.DataFrame, context):
    """One clean turbidity value per minute, from the raw readings around it."""
    # Fault codes arrive as text, with no numeric value.
    readings = frame.dropna(subset=["value"])
    # A spike, such as a bubble past the sensor, sits far from the median.
    threshold = context["parameters"]["threshold"]
    median = readings["value"].median()
    readings = readings[(readings["value"] - median).abs() <= threshold]
    if readings.empty:
        return {"turbidity": readings[["time", "value"]]}

    # Average the remaining readings within each minute.
    minutes = readings.resample("1min", on="time")["value"].mean()
    # Fill gaps between valid minutes; keep the edges unfilled.
    filled = minutes.interpolate(limit_area="inside")
    # Return the calculated series. The app maintains its one-minute grid.
    return {"turbidity": filled.dropna().rename("value").rename_axis("time").reset_index()}

Deploy the alarm#

The alarm uses the same measurement query, which now selects the cleaned values. Its settings give each location a limit and duration. Output(on_group=True) attaches the result to the location so you can query for a filter’s alarm.

# The same query now reads the cleaner's output.
alarm_app = aq.App(
    name="turbidity-alarm",
    inputs={
        "turbidity": aq.Selection.from_query(
            turbidity,
            measurement="turbidity",
            group="location",
            parameters={
                "urn:turbidity:filter-1": {"limit_ntu": 0.5, "sustained_minutes": 15},
                "urn:turbidity:filter-2": {"limit_ntu": 0.5, "sustained_minutes": 15},
                "urn:turbidity:filter-3": {"limit_ntu": 0.5, "sustained_minutes": 15},
                # The combined outlet uses a lower limit and shorter duration.
                "urn:turbidity:combined": {"limit_ntu": 0.3, "sustained_minutes": 5},
            },
        ),
    },
    # Attach the alarm to its plant location for queries.
    outputs={"alarm": aq.Output(on_group=True)},
    function=aq.PythonFunction.from_file(calculations, "alarm"),
    # Read enough history for the longest configured duration.
    window=aq.Rolling(lookback=pd.Timedelta("15m"), step=pd.Timedelta("1m")),
)
client.deploy_app(alarm_app)

Sustained turbidity threshold#

The alarm receives a Polars dataframe (pl.DataFrame) of cleaned readings. context["output_time"] is the minute being checked. For Filter 3 the alarm requires 15 consecutive one-minute values above 0.5 NTU. Acquirium stamps the returned number at the output time. A 1 means the alarm is on and a 0 means it is off.

def alarm(frame: pl.DataFrame, context):
    """1 when clean turbidity stayed above the limit for the whole duration."""
    t = pd.Timestamp(context["output_time"])
    # Report only at minutes that have a clean value.
    if frame.filter(pl.col("time") == t).is_empty():
        return {"alarm": None}

    limit = context["parameters"]["limit_ntu"]
    minutes = context["parameters"]["sustained_minutes"]
    recent = frame.filter(pl.col("time") > t + pd.Timedelta(f"-{minutes}m"))
    sustained = recent.height == minutes and recent["value"].min() > limit
    return {"alarm": 1 if sustained else 0}

Read the results#

Once both apps are deployed, the script inserts the sample readings. Filter 3 stays above the limit from 00:02 through 00:20. The cleaner fills the gap at 00:10, so the alarm is on for five minutes, from 00:16 through 00:20. To inspect the original analyser samples alongside the cleaned values, see reading replacement outputs.

Late readings and alarm recalculation#

The script inserts two late readings for the gap at 00:10.

# The missing readings show a brief dip below the alarm limit.
missing_minute = START + 10 * MINUTE
receipt = client.insert_timeseries(SOURCE, "filter-3", [
    (missing_minute, 0.15),
    (missing_minute + MINUTE / 2, 0.25),
])["receipts"][0]
client.wait(receipt)

The clean value changes from 0.80 to 0.20 NTU, splitting the high period into two runs that are too short to trigger the alarm. An epoch identifies a published version of the data. Reading the alarm with epoch=first_epoch shows its state before the late readings.
