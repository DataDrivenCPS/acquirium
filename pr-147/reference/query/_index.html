Query#

A Query describes a pattern of nodes in the plant model: entities, properties and the streams connected to them. Builder methods add nodes and filters and return a new Query. Reading methods run the pattern and return tables, Python objects or a DataObject that holds the time series. This section lists every public method of Query, the attribute expressions used in filters, and the objects a query returns.

Terms#

  • Node: one part of the query pattern. A query has entity nodes, property nodes and measurement nodes.

  • Alias: the name of a node. It is the column name in the metadata table and the handle other methods take in frm=, of= and target=.

  • Current node: the node added last. Methods act on it unless another alias is given. Query.refocus changes it.

  • Measurement node: a node that matches properties with a stream connected. Only measurement nodes return time series.

  • Attribute: a named value of a node, such as unit or label. See Built-in attributes.

Every builder method returns a new Query and leaves the original unchanged. A query can be kept in a variable and extended in several ways.

Example setup#

The examples in this section use the example plant that ships with the package, with one day of generated data. Stream registration and inserts are documented in streams, timeseries, graph and metadata.

from datetime import datetime, timezone

import acquirium as aq
from acquirium.examples import seawater_ro

acq = aq.init()
acq.insert_graph_file(seawater_ro.model_path, source_id="plant")

start = datetime(2026, 1, 1, tzinfo=timezone.utc)
end = datetime(2026, 1, 2, tzinfo=timezone.utc)
data = seawater_ro.generate(start, end)

acq.register_streams([
    {"source_id": "plant-data", "stream_name": name, "property_uri": "urn:swro/" + name}
    for name in data
])
acq.insert_timeseries_batch("plant-data", data)

acq.insert_metadata("wbs:P1", {
    "product_info": {"manufacturer": "Grundfos", "year": 2019},
    "tags": ["critical", "high-pressure"],
})
acq.insert_metadata("wbs:P2", {
    "product_info": {"manufacturer": "Siemens", "year": 2012},
    "tags": ["booster"],
})

The model has three pumps (wbs:intake, wbs:P1, wbs:P2) and 32 properties, each with one stream. The order of rows in a metadata table is not fixed. It can differ from the outputs shown here.
