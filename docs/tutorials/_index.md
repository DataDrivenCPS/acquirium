The tutorials teach Acquirium step by step. Start with [getting started](getting-started.md), which installs Acquirium and runs a first query.
The querying and data tutorials use the WaterTAP seawater-RO model. The driver and app tutorials show how to ingest your own data and calculate derived streams.

- [Getting started](getting-started.md) — install Acquirium, generate a config file, start a server and run one query
- [Querying](querying.md) — select equipment, follow connections and find measurements with the `Query` interface
- [Query cookbook](query-cookbook.md) — queries for common questions a plant engineer asks
- [Working with data](data.md) — fetch timeseries, choose the frame shape, convert units and split the result
- [Your first driver](first-driver.md) — ingest a CSV export and give every column its unit and quantity kind
- [A driver against an existing plant model](driver-with-a-plant-model.md) — attach a driver's streams to the points of a loaded plant model
- [Your first app](first-app.md) — run an app that converts temperature readings and query the derived values
