These pages list every method, option and endpoint. They describe what each one
does rather than when to use it; the [tutorials](../tutorials/_index.md) and
[how-to guides](../how-to/_index.md) cover that.

- [Client API](client-api.md): `Acquirium`, `Query`, `DataObject` and `AcquiriumClient`.
- [Drivers](drivers.md): base classes, hooks, configuration keys, and the built-in drivers.
- [Apps](apps.md): selections, outputs, windows, functions, and deployment.
- [Experiments](experiments.md): Studies, variables, runs, and stream annotations.
- [Server configuration](server-config.md): `[server]` settings, environment variables, ontologies, drivers and apps.
- [Storage upgrades and recovery](storage-migrations.md): schema upgrades, backups, and restore.
- [HTTP API](http-api.md): the server's endpoints.
- [Glossary](glossary.md): the terms these docs use.
